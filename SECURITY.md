# Politique de sécurité

## Versions maintenues

| Version | Maintenue |
| ------- | --------- |
| 4.x     | oui       |
| 3.9.x   | correctifs uniquement |
| < 3.9   | non       |

## Signaler une faille

N'ouvrez pas d'issue publique. Utilisez un avis de sécurité privé GitHub
(https://github.com/ccmbenchmark/ting/security/advisories/new) ou écrivez aux
mainteneurs listés dans `.github/CODEOWNERS`. Un accusé de réception est envoyé
sous 5 jours ouvrés ; le correctif est publié dans une version de patch avec
une entrée `CHANGELOG` préfixée « Fix security ».
